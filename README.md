# FitnessTracker 💪

A modern fitness and workout tracking web application built with React.

![FitnessTracker](https://img.shields.io/badge/React-18.0-blue) ![Status](https://img.shields.io/badge/Status-Live-success)

## ✨ Features

- 💪 **Workout Logging** - Track exercises with duration and calories
- 📊 **Dashboard** - View stats and progress
- 🎯 **Goal Setting** - Set weekly workout and calorie targets
- 🎨 **White & Blue Theme** - Clean, energetic design
- 📱 **Responsive** - Works on all devices
- 🎭 **Smooth Animations** - Fade-in effects, hover animations
- 🍔 **Dropdown Menu** - Easy navigation
- 📈 **Progress Tracking** - Visual progress bars
- 💾 **Local Storage** - Data persists across sessions
- 🏋️ **Exercise Library** - 6 different exercises

## 🚀 Live Demo

**Visit:** [FitnessTracker Live](https://fitnesstracker-app.vercel.app)

## 🛠️ Tech Stack

- **React 18** - UI library
- **Create React App** - Build tool
- **Vanilla CSS** - Styling
- **JavaScript (ES6+)** - Logic
- **LocalStorage** - Data persistence

## 📦 Installation

```bash
git clone https://github.com/chandanhastantram/fitnesstracker-app.git
cd fitnesstracker-app
npm install
npm start
```
